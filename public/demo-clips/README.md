# Demo clips

Drop **5–10 short face videos** here (`.mp4`, `.webm`, or `.mov`).

In the app, click **Load demo set** to queue every clip in this folder (up to 10). They stay in your browser — nothing is uploaded.

Suggested: frontal face, ~8–15 seconds, decent light. Filenames sort alphabetically in the session slider.

After adding files, restart `npm run dev` (or refresh) so the list updates. A `manifest.json` is written on `npm run build` for static hosting.
